# STREAM SCANNER

موقع ويب مستقل لفحص مصادر الفيديو العامة الظاهرة في صفحات HTML.

## تشغيل محلي
يتطلب Node.js 20 أو أحدث:
```bash
npm install
npm start
```
ثم افتح `http://localhost:3000`.

## النشر على Render
1. ارفع محتويات هذا المشروع إلى مستودع GitHub مستقل اسمه `stream-scanner`.
2. في Render اختر **New + → Web Service** ثم اربط مستودع `stream-scanner`.
3. الإعدادات:
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free
4. انتظر انتهاء النشر وافتح رابط `onrender.com` الذي يظهر لك.

## حدود الفحص
- يقرأ HTML الثابت وعناصر `video`, `source`, `iframe`, `embed`, والروابط التي تظهر في النص.
- لا ينفذ JavaScript داخل الصفحة، ولا يفك DRM، ولا يتجاوز تسجيل الدخول أو CAPTCHA أو حماية مزود البث.
- بعض روابط البث تتطلب Cookies أو Referer أو Token أو صلاحيات؛ ظهور الرابط لا يعني أنه سيعمل في أي مشغل.
- خطة Render المجانية قد توقف الخدمة عند الخمول وتحتاج وقتًا للاستيقاظ.

## أمان
الخادم يقصر الطلبات على HTTP/HTTPS، ويرفض المضيفين والعناوين المحلية/الخاصة، ويتحقق من التحويلات، ويضع حدودًا للحجم والوقت وعدد النتائج. لا تستخدمه لفحص خدمات لا تملك الإذن لاختبارها.
